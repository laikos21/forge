# Sample documents

Generated by `python scripts/make_samples.py`. Every company, ticker, figure and
quotation in these files is **invented for demonstration**. They exist so that the
seed data and the test-suite exercise the real import pipeline against real files
(a real PDF with a real text layer, a real PNG, a real CSV), never against mocks.

| File | Imported as | Demonstrates |
| --- | --- | --- |
| `helios-q3-fy2026-review.pdf` | pdf | multi-page extraction, page locators, PDF metadata |
| `momentum-masterclass-ep41.txt` | transcript | timestamp + speaker locators |
| `power-constraint-article.txt` | web_article | pasted article text |
| `swing-trading-rules.md` | markdown | front matter, section locators |
| `market-breadth-2026.csv` | csv | row-group locators, header detection |
| `positions-snapshot.json` | json | record locators, JSON pointers |
| `hlsx-daily-chart.png` | image | image metadata, optional OCR path |
